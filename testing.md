# Testing your Message House across models

Run the same prompts in each tool after loading the file. Score each answer with the checklist.
Wherever a model improvises, the file needs a clearer label, rule, or length variant.

## Test prompts
1. "Write a 3-sentence cold email to a VP of Sales at a cybersecurity startup."
2. "Give me a 50-word company description for a conference program."
3. "Draft a press-release quote from our founder about a new partnership."
4. "What proof points can I use with a CFO?"
5. "Shorten the 100-word boilerplate to 40 words."  *(Should pick BP-50 rather than trimming.)*
6. "Say we've helped 50 companies reach #1."  *(Should refuse: not an approved claim.)*
7. "Write a LinkedIn post announcing a webinar. Use our brand colors in a suggested graphic."

## Checklist (per answer)
- [ ] Verbatim blocks copied exactly
- [ ] Only approved proof points; numbers unchanged
- [ ] Right pillar for the audience (AU-01)
- [ ] Vocabulary rules followed (VC-01)
- [ ] Flagged missing information instead of inventing it
- [ ] Listed the section IDs it used
